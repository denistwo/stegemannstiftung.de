# stegemannstiftung.de

Einseitige Website der Gisela und Hermann Stegemann-Stiftung. Statisches HTML ohne
Framework, ohne externe Ressourcen (keine Fonts, kein Tracking, keine Cookies) —
Voraussetzung dafür, dass die Datenschutzerklärung so knapp bleiben kann.

Gehostet über GitHub Pages, ausgeliefert unter der eigenen Domain (siehe `CNAME`).
Anlass war die Domain-Verifizierung für Google Workspace for Nonprofits.

- `index.html` — die gesamte Seite inklusive Impressum und Datenschutz
- `logo.svg` — vom Stiftungsvorstand am 17.06.2026 angenommene Variante
